# Envio para o GitHub

Etapa 1: código-fonte, páginas, painel administrativo, estilos, dependências e configurações do projeto original.

As fotos, imagens, ícones e o vídeo de `public/` serão enviados na próxima etapa, mantendo os nomes e caminhos usados no código. Os diretórios estão reservados com `.gitkeep`.

Esta etapa ainda não apresenta o visual completo sem os arquivos de mídia.

O projeto original utiliza Vinext, Cloudflare D1 e autenticação do ChatGPT Sites. Uma publicação em outro provedor exige configurar ou adaptar o banco de dados e a autenticação; o envio ao GitHub não realiza essa migração.
